# 관리자 7일 쿠키 세션 구현 계획

## 작업 1: 세션 쿠키 서명·검증

1. 유효한 쿠키, 변조, 만료, 권한 부족을 검증하는 실패 테스트를 작성한다.
2. Web Crypto HMAC 서명과 쿠키 인증 공급자를 최소 구현한다.
3. 인증 경계 테스트를 통과시킨다.

## 작업 2: 인증 API

1. 로그인 성공·실패, 설정 누락, 세션 확인, 로그아웃 쿠키 제거 실패 테스트를 작성한다.
2. Zod 요청·응답 계약과 인증 핸들러를 구현한다.
3. Route Handler 세 경로를 Worker 비밀 바인딩에 연결한다.

## 작업 3: 관리자 문의 연결과 문서

1. 관리자 문의 API가 서명 쿠키를 허용하고 미인증·권한 부족을 구분하는 테스트를 작성한다.
2. 기존 메모리 공급자를 실제 경로에서 제거한다.
3. README에 API, 바인딩 이름, 서명 쿠키 선택과 폐기 한계를 기록한다.

## 작업 4: 전체 검증과 검토

`pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm format:check`, `pnpm build`를 실행한다. 운영 D1 검증과 배포는 실행하지 않는다. 전체 변경을 별도 시각으로 검토한 뒤 커밋·푸시·PR을 만든다.
